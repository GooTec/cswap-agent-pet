# Chiikawa Agent Pet v1.0.0

This combined release was not published. Use [mac v1.0.0](mac-v1.0.0.md) or [Windows v1.0.0](windows-v1.0.0.md) instead.

Floating Chiikawa, Hachiware, and Usagi pets with Claude and Codex subscription quota displays.

## Downloads

| File | Platform | Install |
|---|---|---|
| `ChiikawaPet-1.0.0-macos-arm64.dmg` | macOS 14+, Apple Silicon | Open the DMG and drag the app to Applications. |
| `ChiikawaPet-1.0.0-macos-x86_64.dmg` | macOS 14+, Intel | Open the DMG and drag the app to Applications. |
| `ChiikawaPet-1.0.0-win-x64-setup.exe` | Windows 10/11, x64 | Run the installer. It installs for the current user. |
| `ChiikawaPet-1.0.0-win-x64.zip` | Windows 10/11, x64 | Extract everything and run `ChiikawaPet.exe`. |
| `SHA256SUMS` | All | Verify downloaded files with SHA-256. |

The Windows packages include .NET. Log in through Claude Code or Codex, then refresh the pet's usage panel.

## Notes

- macOS and Windows use their existing native implementations: Swift/AppKit/SwiftUI and C#/.NET/WPF.
- Windows supports local credential files; Credential Manager-only accounts are not supported.
- macOS builds, resource bundles, and Swift tests are verified. Windows cross-builds and logic checks are verified; Windows GUI and installer execution still need a Windows test.
- Packages have no Apple Developer ID notarization or Windows code-signing certificate.
- Source code is MIT licensed. Character artwork and service logos are excluded; the artwork notice is included in each package.
