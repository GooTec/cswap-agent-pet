# Chiikawa Agent Pet Windows v1.0.0

Floating Chiikawa, Hachiware, and Usagi pets for Windows 10/11 x64, with Claude and Codex quota displays.

| File | Install |
|---|---|
| `ChiikawaPet-1.0.0-win-x64-setup.exe` | Run the installer; open Chiikawa Pet from the Start menu. |
| `ChiikawaPet-1.0.0-win-x64.zip` | Extract all files and run `ChiikawaPet.exe`. |
| `SHA256SUMS` | Verify downloads with SHA-256. |

.NET and its license notices are included. The installer installs for the current
user and provides an uninstall entry. Settings and CLI credentials are preserved on uninstall.

Use the notification-area icon if the pet is hidden. Windows Credential
Manager-only login storage is not supported. Packages have no code-signing certificate;
mixed-DPI and visual behavior still require manual verification on Windows.

Source code is MIT licensed. Character artwork and provider logos are excluded;
each package includes the separate artwork notice.
