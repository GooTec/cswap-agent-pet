# Chiikawa Agent Pet mac v1.0.0

Floating Chiikawa, Hachiware, and Usagi pets for macOS 14+, with Claude and Codex quota displays.

| File | CPU | Install |
|---|---|---|
| `ChiikawaPet-1.0.0-mac-arm64.dmg` | Apple Silicon | Open the DMG and drag the app to Applications. |
| `ChiikawaPet-1.0.0-mac-x86_64.dmg` | Intel | Open the DMG and drag the app to Applications. |
| `SHA256SUMS` | Both | Verify downloads with SHA-256. |

Click the pet for quota details, drag to move it, or use its menu-bar controls.
Existing Claude Code and Codex logins are supported. Preferences persist between launches.

The app is ad-hoc signed; Apple Developer ID notarization is not configured.
Source code is MIT licensed. Character artwork and provider logos are excluded;
each package includes the separate artwork notice.
